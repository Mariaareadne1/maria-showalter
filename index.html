01 Selected work
Web Audio · JavaScript

TONUS

A polyphonic web synthesizer built from scratch. FM, AM (ring modulation), additive (10 harmonics), and subtractive synthesis crossfaded in real time. Per-voice ADSR envelopes, LFO, a chord generator modelled on the Nopia MIDI controller, oscilloscope, spectrum analyzer, and record-to-file. No dependencies, no build step — ~1,700 lines, runs entirely in the browser.

Built for COMS 3430 — Computational Sound, then kept going.

02 About

I'm a B.A. Computer Science student at Columbia University (minor in Hellenic Studies), graduating 2028. My work sits at the intersection of software engineering and music: I write code that makes sound, and I build the tools other people use to do the same.

I host Algoraves — live events where music is performed by writing and modifying code in real time — to bring more students into the live coding scene. That practice is why I build audio software: I want to understand the instruments from the inside out.

Alongside that I ship full-stack products and have worked as a data and systems engineer, including building an AI automation pipeline that cut manual data workload by 80%.
